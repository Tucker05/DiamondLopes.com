# DiamondLopes.com

Official source repository for the Diamond GCU website.

- Live domain: https://diamondlopes.com
- Hosting: GitHub Pages
- Domain registrar: IONOS
- Built as a static HTML/CSS/JS site for fast, free hosting.

## Updating the site

Edit `index.html`, `styles.css`, or the files in `assets/`, then commit to `main`. GitHub Pages will publish the new version automatically once Pages is enabled.
